# 明日方舟通行认证 · 印刷文件生成器

一个无构建依赖的 Canvas 编辑器，可在浏览器里生成约 `49.95 × 99.91 mm` 的通行认证正反面印刷文件。

## 功能

- 正面、背面文字与视觉样式实时预览
- 透明角色图上传、拖动、滚轮/键盘缩放
- 正反面彩色成品独立导出，始终排除刀线
- 正反面白墨图：支持“随图透明度”和“刀模内满版白墨”
- 白墨扩边/缩边与透明度阈值
- 与正反面方向一致的 `CutContour` 矢量 SVG 刀线，以及 PNG 参考图
- PNG 自动写入 300 PPI `pHYs` 元数据
- 响应式桌面/移动端界面

## 本地运行

ES Module 需要通过 HTTP 访问，不能直接双击 `index.html`。

```bash
npm run serve
```

然后打开 <http://127.0.0.1:4173/>。

## 测试

```bash
npm test
```

测试覆盖刀模几何、白墨阈值与扩缩边、PNG 分辨率元数据、图层查找和画布坐标换算。

## 印刷说明

- 所有 PNG 均为 `590 × 1180 px`，并写入 300 PPI；彩色、白墨、刀线采用相同坐标系。
- 正面刀线按正面坐标输出；背面刀线及白墨会水平镜像，使左侧缺口与背面看稿方向一致。交付时请明确使用对应面的文件。
- 白墨 PNG 是纯白 RGBA 分色：有 Alpha 的区域代表白墨覆盖，无 Alpha 的区域不出白墨。
- SVG 中的刀线组名为 `CutContour`，但 SVG 本身无法保证 RIP 软件将它自动识别为命名专色。交付前仍需由印厂在 Illustrator、CorelDRAW 或 RIP 软件中确认专色、线宽、出血和正反套印方向。
- 白墨扩缩边的合适数值取决于设备套印精度；默认 `0 mm`，请以印厂要求为准。
